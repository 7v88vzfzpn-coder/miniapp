# 💬 PHP Mini Messenger

A simple web-based messenger built with **PHP, HTML, and CSS**.

This project was created as a small learning project to practice PHP fundamentals and basic web development.

## ✨ Features

- Send messages
- Enter a username
- Display message time
- Store messages in a text file
- Simple responsive interface
- No database required

## 🛠️ Technologies

- PHP
- HTML5
- CSS3

## 📁 Project Structure

```text
mini-messenger/
├── index.php
├── style.css
└── messages.txt
```

## 🚀 Run Locally

Make sure PHP is installed.

Start the built-in PHP server:

```bash
php -S localhost:8000
```

Then open:

```text
http://localhost:8000
```

## 📚 How It Works

When a user sends a message, PHP saves it to `messages.txt`.

Each message contains:

- Time
- Username
- Message text

The messages are then loaded and displayed in the chat interface.
